# Refuted findings — #234 dirty-patch trailing-newline corruption

The same typed finding set `50-panel` raised, carried forward from
`.sergeant/workflows/fix-defect/50-panel/output/findings.md` and updated
in place with a final `status` and, where refuted, the refuter's
argument.

## Refutation disclosure

Four refuter seats — one per axis (`spec-fidelity`, `invariants`,
`simplicity`, `test-honesty`) — were spawned as sub-agents in a single
message, in parallel, each given only its own axis's findings from
`50-panel` plus pointers into the actual current code (not the panel's
paraphrase of it) and asked to attack every finding, independently
re-reading `src/runtime/git.rs`, `src/runtime/surface.rs`, and
`tests/m7_docker_executor.rs` against ground truth. Default posture was
refuted; a finding survived only where its seat could not overturn it
after checking the real code.

Per `@@panel`/`@@fan-out-evidence`, the same disclosure applies here as in
`50-panel`: these are four isolated briefs read by one stage execution,
not four independent reviews. Isolation is context isolation only — each
seat saw only its own axis and nothing of the other three seats'
reasoning — and it is weaker than the isolation a separate Work would
give: all four share this stage's single execution, journal entry, usage
window, and failure mode.

Result: 19/19 findings attacked, 11 confirmed, 8 refuted. No new findings
were added at this stage.
