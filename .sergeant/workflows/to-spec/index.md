# To Spec

Two-stage actor-only workflow (N1 reference corpus, `docs/gauntlet/contracts/N1.md`,
candidate **W31**) that turns a plan/design into a published spec ticket:
gathered context, sketched seams, confirmed with the user, published on
template. Use when: a design needs to be turned into a spec-shaped ticket
before implementation.

See `CONTEXT.md` for workflow orientation and `workflow.toml` for the pinned
stage order. The full behavior-unit citation trail lives in
`docs/icm/promotion-spec-2026-08-11.md` and the archived
`docs/gauntlet/promoted-provenance/to-spec.md` (verbatim copy of this
package's pre-promotion `provenance.md`).
