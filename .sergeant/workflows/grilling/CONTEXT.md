# Grilling
Draft workflow package — candidate **W28** `grilling` from the N1
manual reference-corpus decomposition (`docs/gauntlet/contracts/N1.md`),
decomposed from `reference/sergeant-upstream` per

## Purpose

Grill the user relentlessly about a plan, decision, or idea, one question at a time.

## Trigger

The user wants to stress-test their thinking, or uses a 'grill' trigger phrase.

| Stage | Ladder rung (as extracted) | Durable outcome |
