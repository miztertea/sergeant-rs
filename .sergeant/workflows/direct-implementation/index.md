# Direct Implementation

Five-stage actor-only workflow (N1 reference corpus, candidate **W6**
`direct-implementation`, `docs/gauntlet/contracts/N1.md`) that implements
in the current session, against one owning repository, under the same
delivery contract as a dispatched worker. Use when: the user explicitly
asks to work in this session, and one repository owns the complete
outcome.

See `CONTEXT.md` for workflow orientation and `workflow.toml` for the
pinned stage order. Full behavior-unit citations are archived at
`docs/gauntlet/promoted-provenance/direct-implementation.md`; the curation
act itself is recorded at `docs/icm/promotion-spec-2026-08-11.md`.
