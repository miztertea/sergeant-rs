== P10  which signals let an instrumented process write its profile ==
The measurement behind phase 1's three teardown repairs. src/bin/sleeper.rs
prints, then sleeps 60s; with argv[1]=handle it installs a SIGTERM handler that
calls std::process::exit(0). Built instrumented, run with LLVM_PROFILE_FILE
pointed at an empty directory, killed three ways:

   no handler + SIGTERM     -> 0 profraw written
   handler + SIGTERM        -> 1 profraw written
   handler + SIGKILL        -> 0 profraw written

   -> the at-exit writer runs only on a normal return from main. sgt's daemon
      installs a tokio SIGTERM handler and returns from main (run_until_signal),
      so SIGTERM-first teardown is what makes its profile exist at all; any
      SIGKILL in a run is a hole in the numbers.
