== full-suite behavior under CPU contention (the instrumentation proxy) ==
   `cargo test`, default parallel harness, this container:
     baseline (idle)        37, 39, 36, 38, 39 s   -> 5/5 green
     4 CPU hogs (~1.9x)     71 s                   -> green
     8 CPU hogs (~2.5x)     92 s                   -> green
   Instrumentation is estimated at 1.5-3x, so the suite's wall-clock
   deadlines survived a hand-applied slowdown across most of that range.
   This is a proxy, not the measurement: contention slows everything
   uniformly, while instrumentation slows instrumented code specifically and
   adds profile writes at exit. F2 is the real answer.
