## Outcome (§21.5)

The local Docker executor and the `kind = "execute"` schema: image
resolution/pull/inspect with immutable identity pinning (§16.4), worktree
mount contract (§16.6), default no-network/no-privilege isolation (§16.7),
streaming bounded output capture (§16.9), exit-to-stage mapping (§15.x),
exact cancel/retry/recovery/cleanup (§16.10–16.12), execute lifecycle
events + projections + UI rendering (§19.4). Proof workflow: actor →
execute → actor, with the execute stage's output evidence consumed by the
following actor without Sergeant interpreting it.

[Rule A, retention ruling] Terminal-work projection eviction with
journal re-derivation on access — closes #4; s2-churn slope goes flat
post-settle; evicted views byte-identical; restart indifferent.

[Rule B, retention ruling] `sgt doctor` disk-pressure check (folds #23):
data-dir size, blob share, headroom, growth since daemon start; the
1 GiB-capture test measures blob disk cost beside §22.8's RSS budget; no
blob is written without a journal ref naming it. Rule C's measurement:
rebuild at 1M events, recorded beside the 50k point.
