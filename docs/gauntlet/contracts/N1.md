# N1 — ICM Filesystem Convention + Adjudicated Sergeant Reference Decomposition

Governing document: `reference/proposal-next-iteration-icm-workflows.md`
§§6, 7.1–7.4, 8, 21.2. Content-only milestone: **no engine change, no Rust.**
Proves the ICM taxonomy is understandable and produces the frozen reference
that N2's generator is measured against.

## Outcome

1. **The convention** (`docs/icm/`): the `.sergeant/` catalog layout
   (proposal §7.1), OKF-compatible `index.md` front-matter shape (§7.3),
   the `@@name` shared-context convention (§7.5), helper rules (§7.6), the
   draft publication boundary (`drafts/` is never runnable procedure), the
   behavior-unit and classification record shapes (§9.4–9.5), and the
   engine-gap claim template (§6.7). Documentation of shapes, not tooling.
2. **The reference corpus** (`reference-corpus/`): an adjudicated
   decomposition of the vendored snapshot at `reference/sergeant-upstream`
   (SHA recorded in `reference/UPSTREAM.md`) into the §8.1 layout:
   `source-inventory.md`, `behavior-units.ndjson`, `classification-ledger.md`,
   `permanent-instructions.md`, `draft-workflows/<candidate>/`, `helper-map.md`,
   `shared-context-map.md`, `obsolete-mechanisms.md`, `engine-pressure.md`,
   `provenance-map.md`, and a `FROZEN.md` naming the corpus version, source
   SHA, and adjudication date.

The corpus preserves behavioral intent and traceability, not old filenames or
mechanisms (§8.1). It is "gold" only as a reviewed expected result for this
snapshot (§8.3) — disagreements are preserved as adjudicated evidence, not
erased.

## Method (§8.3, run as a gauntlet workflow)

Inventory → Extract → Normalize → Classify (ICM ladder §6.1–6.7) →
Synthesize → **Refute** (≥2 independent reviewers challenging workflow/stage
boundaries, missing behaviors, and every engine-gap claim) → Adjudicate
(evidence-only; rulings recorded) → Freeze.

Binding rules:

- Every behavior unit cites source path + locator + quote hash; a unit
  without a citation is invention and is rejected at lint, not review.
- Every engine-gap claim names the lower rungs attempted and why each fails
  (§6.7); "would be convenient" is auto-rejected.
- The `dispatch` skill's tmux/sentinel/worker machinery is the designated
  obsolete-mechanism stress test (§8.2): durable procedure must be separated
  from the Bash architecture that carried it, and that separation is itself
  reviewed.
- Tests may outrank documentation as behavioral authority (§5); extraction
  covers `tests/`, `scripts/`, `bin/`, hooks, and templates, not just prose.
- Reviewers read the deviation register and N0 rulings first (L3).

## Unknowns (environmental objects, not builder inferences)

- U1: How many behavior units the 179-file corpus actually yields — scoping
  estimate 150–400; the real number is a finding.
- U2: Whether the ladder's stage test (§6.3 "would the checkpoint survive a
  reimplementation?") discriminates cleanly on `no-mistakes` — expected to be
  the hardest case (§8.2) and the richest source of grammar pressure.
- U3: Whether interactive/consent-gated procedure (`sergeant-setup`) fits
  ordered actor stages or produces the first honest engine-pressure findings
  for `needs_input` semantics.

## Non-goals

No workflow-engine change; no `repo-to-icm` implementation (that is N2); no
generated content in `.sergeant/workflows/` of this repo; no claim the manual
decomposition is perfect; no back-porting fixes into `reference/sergeant-upstream`
(reference is committed evidence — read-only).

## Amendment 2026-08-10 (mid-milestone, owner-directed — register row D9)

The convention adopts the published ICM protocol's four-layer context model
(workflow `CONTEXT.md` orientation; stage `CONTEXT.md` with a mandatory
Inputs table; `references/`/`_config/` stable Layer 3; per-stage `output/`
Layer 4) — see `docs/icm/convention.md` §1a and `record-shapes.md` §1a.
Draft workflow packages produced by this milestone follow the layered
shape. Landed before the Draft phase consumed the convention docs;
behavior-unit extraction (already complete for P1–P7 at amendment time) is
unaffected — representation categories are unchanged.

## Gate (§21.2 verbatim, plus repo standards)

- Every selected source artifact has a disposition in `source-inventory.md`
  (decomposed / helper / obsolete / out-of-scope, each with a reason).
- Every candidate workflow traces to behavior units, not file shape.
- ≥2 independent reviewers challenged workflow and stage boundaries; their
  findings and dispositions are in `classification-ledger.md`.
- Unresolved disagreements are explicit entries, not silence.
- A structural lint pass (helper script or manual checklist this milestone)
  verifies: citation completeness, unique names, no draft outside
  `draft-workflows/`, engine-gap template completeness.
- `cargo fmt --check && clippy && test` stay green (content-only, but the
  gate proves no accidental tree damage).
- Ledger entry with both scorecards; corpus frozen with version + SHA.
