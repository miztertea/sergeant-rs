# N2 — Actor-Only `repo-to-icm` on the Current Engine

Governing: proposal §9, §21.3; convention `docs/icm/` (D9 four-layer,
dispositions + finalize); measured against the frozen reference
(`reference-corpus/FROZEN.md`, v1). No engine change.

## Outcome

1. **The workflow**: `.sergeant/workflows/repo-to-icm/` — the §9.3 ten-stage
   shape (contract → inventory → harvest → normalize → classify → synthesize
   → draft → lint → adversarial-review → reconcile), authored to this repo's
   own convention: layered contexts with Inputs tables, stage `references/`
   carrying the ladder and record shapes by reference, declared `output/`
   artifacts with dispositions, a finalize helper, and the §9.7 structural
   validator as a workflow helper. It must itself pass `reference-corpus/`-
   grade lint (the validator runs on its own tree).
2. **Measurement run #1**: executed through the real `sgt` daemon against
   `reference/sergeant-upstream` at the frozen SHA, blind to
   `reference-corpus/` (the run's actors never read it; enforced by prompt
   and checked at review). The fake backend drives stage lifecycle; its
   hold-open/advance semantics are **measured before use** (L1 — the P1
   FIFO semantics are the starting point, not the assumption). Each stage's
   actor work is performed by a fresh agent given exactly that stage's
   pinned context from the work surface. Full trajectory (journal events,
   stage transitions, worktree diffs) is part of the deliverable.
3. **Blind comparison**: generated output vs reference corpus v1 — three
   independent comparers over disjoint §9.9 dimension groups, an
   adjudicator over their disagreement set, classified per §9.8 (generator
   miss / generator invention / gold miss / legitimate alternate / ambiguous
   source / genuine engine pressure). Success criterion is §22.2's: no
   reference behavior with safety/identity/recovery/delivery/human-decision
   consequence silently absent.
4. **Grammar-pressure report**: what the ordered-actor grammar could and
   could not express, each "could not" carrying the §6.7 lower-rung
   template. This document licenses (or defers) Program B scope.
5. **Runs #2–#3** (different instruction cultures, per §9.10) may follow in
   a later entry if capacity allows; run #1 closes this contract.

## Unknowns

- U1: fake-backend hold-open semantics under `waiting` steps across stage
  boundaries — measure first.
- U2: whether stage-scoped agents given only pinned context + worktree
  reproduce ≥ the reference's behavioral recall without cross-stage leakage.
- U3: whether the finalize/disposition convention survives its first real
  workflow (open question from D9).

## Non-goals

No publication of generated drafts; no engine change; no semantic workflow
selection; no real-Claude requirement for run #1 (the fake-backend run is
the workflow-mechanics proof; a real-Claude measurement run may follow to
close #19 per R-N0-6 — if run here, its cost is recorded).

## Gate

Reproducible from named SHAs; §22.1 items 1–10; comparison scorecard
published (§9.9 dimensions, no single accuracy number); every engine-gap
claim carries failed lower rungs; drafts confined to the draft namespace of
the *run worktree*; gates + `pgrep` hygiene; ledger entry with both
scorecards; workflow scripts archived.
