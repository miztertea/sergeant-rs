# S0 Contract — S-Series Kickoff Adjudication

Adjudication-only milestone (N0 precedent): no code delta. Outcome: the
S-series proposal (`reference/proposal-s-series-stabilization.md`) is
challenged by a fresh-context panel, every finding ruled, the proposal
amended, and the rulings below recorded as binding on S1–S2. Challenge
record and full disposition table: `docs/gauntlet/notes/s0-adjudication.md`.

Owner directions of 2026-08-10 are inputs to this adjudication, not its
products: S-series naming; fix policy (minor blocking fixes roll in,
breaking changes are discussed, the rest becomes issues); CI must not slow
prototyping; workflow `.js` lives in `resources/`; the program runs
autonomously.

## Rulings

- **R-S0-1 — Gate regime (R4: platform reality).** The no-mistakes pipeline
  is absent from this container, so the shipping gate for S-milestones is
  the Bug Sprint 1 precedent: orchestrator-verified `fmt --check` /
  `clippy --all-targets -- -D warnings` / `test`, plus the hygiene sweep
  (zero leaked daemons — pgrep pattern extended to `llvm-cov-target` — and
  zero `/tmp` residue), recorded per milestone in the ledger. Trigger to
  revisit: the pipeline returns to the environment.
- **R-S0-2 — Toolchain drift guard (R6: one recorded check).**
  `rust-toolchain.toml` keeps floating `stable`; the harness records
  `rustc -vV` + cargo-llvm-cov version per run and refuses cross-version
  profdata merges. The baseline quotes both.
- **R-S0-3 — Measurement convention (binding; the L11 clause).** The exact
  collection and report command lines are committed in `scripts/coverage/`
  and quoted verbatim in the baseline doc; convention constants (dev
  profile, default llvm-cov target dir, report scope `src/**`, no
  `--ignored`) are stated once there. A number produced any other way is
  not the program's number. Tool semantics asserted anywhere are hypotheses
  until the S1 builder measures them (L1 at the tool boundary).
- **R-S0-4 — S1 ordering (R6: sequencing, no machinery).** Phase 1
  instrument/hygiene commits → SHA frozen; phase 2 measurement against that
  SHA only, any mid-phase repair restarts phase 2; phase 3 publication.
- **R-S0-5 — L7 applies to instrument repairs.** No roll-in is exempt from
  "a fix without a test that fails when the fix is reverted is not done."
  Pinning shapes named up front: `SpawnedDaemon::drop` → assert
  SIGTERM-exit (not SIGKILL); reaper signal-reporting → extend the existing
  reaper test; demo.sh teardown → in-script fail-closed verify-gone check
  (partial pin, limitation recorded); CI/`.gitattributes` → config verified
  by observation, recorded as such. A repair whose pin would be
  unfalsifiable moves to discuss-first.
- **R-S0-6 — Resource and integrity accounting (R2: reuse df/llvm
  tooling).** Harness pre-flights disk and refuses any stage under 10 GB
  free; profraws cleaned between census runs; at most two build trees ever
  (`target/`, `target/llvm-cov-target`); per-stage profraw accounting
  (produced/merged/discarded) with failure on unaccounted loss.
- **R-S0-7 — Flake census parameters.** Control arm N=10 uninstrumented
  full-suite runs (M3 precedent); instrumented arm N=3; both default
  parallel harness; ~4 h ceiling with blocked-with-reason shortfall
  recording; a once-observed failure that misses 3 targeted re-runs is
  "observed, unreproduced" by name, escalating to an issue only on
  recurrence. "Fails only under instrumentation" requires a green control
  arm.
- **R-S0-8 — Provenance over tidiness (R1: don't do it).** The tracked
  vendored `.pyc` under `reference/sergeant-upstream/` stays —
  `reference/UPSTREAM.md` pins byte identity to an upstream SHA and the
  file never affected the language bar. `.gitignore` gains
  `__pycache__/`/`*.pyc` to prevent new ones.
- **R-S0-9 — S3 demoted (R1: milestone need not exist).** The CI coverage
  lane is one workflow file plus one number; it lands as a rung-logged S2
  close-out commit proven by a single `workflow_dispatch` run.
- **R-S0-10 — `Cargo.toml` owned by neither program.** The S-series has no
  current need; a test-dependency need in S2 is contract material.
- **R-S0-11 — Findings pipeline.** Orchestrator files issues via GitHub MCP
  tooling; fallback is `docs/coverage/findings-<date>.md` committed beside
  the baseline and transcribed later — never dropped. Deduped by
  subsystem/root-cause (P1-PERF #5 precedent), capped at 12, each naming
  the unexercised behavior. S1 ships `.github/ISSUE_TEMPLATE/
  coverage-gap.yml` with `labels: ["coverage"]`.

## Addendum — 2026-08-10, post-phase-1 (owner challenge)

- **R-S0-12 — Code is code.** Any diff that changes executable behavior —
  `src/`, `tests/`, `scripts/`, workflow `.js`, CI config — takes the full
  loop regardless of milestone template: multi-axis blind panel
  (spec-fidelity, test-honesty, invariants/simplicity at minimum),
  adversarial verify, fix round, orchestrator adjudication, under the
  R-S0-1 gate regime. The P1-PERF single-builder exemption applies only to
  phases that write no code, and a builder's probe of its own pin is
  evidence for the panel, never a substitute for it
  (`gauntlet-pattern.md`: builders never grade their own work). Process
  error acknowledged: S1 phase 1 launched as a single builder under a
  stretched P1 precedent; corrected before the measurement SHA froze
  (three-axis lean round 2, `resources/s1-instrument-round2-lean.js`).
  LESSONS candidate at S1 MARK & LOG.
