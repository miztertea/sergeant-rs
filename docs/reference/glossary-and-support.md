# Glossary and support

- **Captain:** interactive harness plus estate doctrine and skills; owns ambiguity and accepted intent.
- **Estate:** exact-root collection of repositories, groups, profiles, AgentOS content, and runtime state.
- **Mount:** clean estate-owned checkout at `repos/<name>`.
- **Work:** durable accepted intent, scope, procedure, state, and evidence.
- **Surface:** Work-owned linked worktree for one targeted repository.
- **Workflow:** pinned, ordered filesystem procedure.
- **Stage:** one fresh actor or deterministic execute unit within a workflow.
- **Profile:** named harness launch configuration; never an authentication broker.
- **Journal:** append-only durable evidence from which projections are rebuilt.
- **Projection:** derived operational view such as analytics or telemetry.

## Versioning and support

Sergeant is pre-1.0. Configuration, CLI, API, JSON, watch, workflow grammar, and backend support can change between minor releases. The Git tag is the documentation version: docs at `v0.2.4` describe `v0.2.4`; docs on `main` describe development `main`. Read [CHANGELOG.md](../../CHANGELOG.md) before upgrading and pin automation to an explicit release.

Supported targets are x86_64 Linux, Apple Silicon macOS, and Windows through WSL2. Report security issues through [SECURITY.md](../../SECURITY.md) and product defects through the public issue tracker.
