# Captain skills

Skills are interactive Captain technique. They run inside the current harness conversation and are not submitted as Work.

| Skill | Use |
|---|---|
| `brainstorm` | explore goals, approaches, and constraints before an intent is precise |
| `clarify-intent` | remove ambiguity before acceptance |
| `decide` | compare alternatives and make an explicit decision with the human |
| `decompose` | split an approved intent into independently executable child intents |
| `define-acceptance` | make success and evidence explicit |
| `estate-navigation` | inspect and reconcile estate topology |
| `grilling` | interview an incomplete idea live |
| `orient` | establish relevant current context |
| `plan-sprint` | organize a bounded delivery cadence |
| `retrospective` | extract lessons after completion |
| `review-outcome` | evaluate returned Work evidence |
| `scope-intent` | select repositories and boundaries |
| `select-workflow` | inspect the current catalog and recommend procedure |
| `sergeant-help` | answer installation, configuration, and diagnosis questions |

Each `skills/<name>/SKILL.md` is authoritative for its trigger and procedure. This index is checked alongside the shipped directory when the catalog changes.
