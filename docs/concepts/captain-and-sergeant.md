# Captain and Sergeant

Captain is a coding harness specialized by estate doctrine and interactive skills. It talks with the user, discovers topology, clarifies intent, chooses scope and procedure, and decides when intent is ready to leave the conversation.

Sergeant is the durable execution engine. It accepts already-shaped intent, pins the workflow and execution decisions, creates Work-owned Git surfaces, runs ordered stages, journals evidence, and reaches an explicit terminal or attention state independently of the original conversation.

Skills teach Captain how to perform interactive technique. Workflows tell Sergeant how accepted intent is completed. Neither is a more convenient spelling for the other.
