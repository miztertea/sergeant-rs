# Security Policy

## Reporting a vulnerability

Please report security vulnerabilities through
[GitHub private vulnerability reporting](https://github.com/miztertea/sergeant-rs/security/advisories/new)
rather than a public issue. It's enabled on this repository and is the
preferred channel: it reaches the maintainer directly and keeps the report
out of the public tracker until a fix is ready.

Sergeant is a solo-maintainer project. There is no formal response-time SLA —
reports are triaged as they arrive, on a best-effort basis.

## Supported versions

Sergeant is pre-1.0. The `main` branch and the most recent published release
are the only lines that receive fixes; there is no long-term support branch
for older releases.

## How security releases are communicated

A fix ships as a normal GitHub Release with release notes describing the
issue at a level appropriate for public disclosure, coordinated with the
reporter beforehand where practical. There is no separate mailing list or
announcement channel — watch the repository's Releases page.
